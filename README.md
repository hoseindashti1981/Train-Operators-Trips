# لوحه‌ساز سیر و اعزام

وب‌اپ پردازش گزارش روزانه راهبران خط ۵ (گلشهر ↔ صادقیه).

گزارش اولیه `.xls` / `.xlsx` را بارگذاری کنید؛ برنامه فقط راهبر (مستر / H1) و کمک‌راهبر (اسلیو / R) را روی ساعت‌های لوحه خروجی می‌گذارد و یک شیت جدا با اسامی مرتب‌شده بر اساس فامیل می‌سازد.

## اجرای آنلاین

[https://hoseindashti1981.github.io/Train-Operators-Trips/](https://hoseindashti1981.github.io/Train-Operators-Trips/)

این آدرس نسخهٔ استاتیک است (GitHub Pages). بعد از هر push به `main` خودش به‌روز می‌شود.

## اجرا روی سیستم خودتان

نیاز: [Node.js](https://nodejs.org) نسخه ۲۰ به بالا.

```bash
git clone https://github.com/hoseindashti1981/Train-Operators-Trips.git
cd Train-Operators-Trips
npm install
npm run dev
```

سپس در مرورگر باز کنید: [http://localhost:8080](http://localhost:8080)

- **بارگذاری اولیه:** فایل گزارش روزانه
- **نمونه گزارش:** فایل نمونه داخل پروژه
- **ساعات خروجی:** ویرایش ساعت‌های لوحه (روز عادی / پنجشنبه / جمعه) — در همین مرورگر ذخیره می‌شود
- **خروجی اکسل:** شیت‌های پردازش، گزارش راهبران، جزئیات، هشدارها

## تطبیق نام‌ها

جستجو فقط روی ساعت نیست. ستون‌ها از روی عنوان پیدا می‌شوند (جای ستون عوض شود هم کار می‌کند) و تطبیق با **مبدأ + ساعت + نقش** است.

## تکنولوژی

TypeScript، React، TanStack Start، SheetJS (`xlsx`).

## نصب به‌صورت PWA (تقریباً آفلاین)

بعد از باز شدن نسخهٔ آنلاین یا `npm run build`، مرورگر دکمه **نصب روی دستگاه** را نشان می‌دهد (در آیفون: Share → Add to Home Screen).

بار اول باید آنلاین باز شود تا برنامه، فونت و کتابخانه اکسل ذخیره شوند. از آن به بعد:

- باز کردن اپ بدون اینترنت
- بارگذاری فایل `.xls` از خود دستگاه
- ویرایش ساعت‌ها (در همین مرورگر ذخیره می‌شود)
- ساخت خروجی اکسل

نمونه گزارش فقط اگر یک‌بار آنلاین گرفته شده باشد آفلاین کار می‌کند.
