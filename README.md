# لوحه‌ساز سیر و اعزام

وب‌اپ پردازش گزارش روزانه راهبران خط ۵ (گلشهر ↔ صادقیه).

گزارش اولیه `.xls` / `.xlsx` را بارگذاری کنید؛ برنامه فقط راهبر (مستر / H1) و کمک‌راهبر (اسلیو / R) را روی ساعت‌های لوحه خروجی می‌گذارد و یک شیت جدا با اسامی مرتب‌شده بر اساس فامیل می‌سازد.

نقشهٔ کامل فنی، جریان کار و روابط کد: **[TECHNICAL.md](TECHNICAL.md)**

## اجرای آنلاین

نسخهٔ قابل‌نصب (PWA):

[https://hoseindashti1981.github.io/Train-Operators-Trips/docs/](https://hoseindashti1981.github.io/Train-Operators-Trips/docs/)

آدرس ریشه فعلاً به همین مسیر هدایت می‌شود. در کروم دسکتاپ/اندروید: منوی مرورگر → **Install app**. در آیفون: Share → Add to Home Screen.

بار اول آنلاین باز کنید تا سرویس‌ورکر، فونت و کتابخانه اکسل ذخیره شود؛ بعدش فایل محلی را بدون اینترنت هم پردازش می‌کند.

## اجرا روی سیستم خودتان

نیاز: [Node.js](https://nodejs.org) نسخه ۲۰ به بالا.

```bash
git clone https://github.com/hoseindashti1981/Train-Operators-Trips.git
cd Train-Operators-Trips
npm install
npm run dev
```

سپس در مرورگر باز کنید: [http://localhost:8080](http://localhost:8080)

- **بارگذاری اولیه:** فایل گزارش روزانه
- **نمونه گزارش:** فایل نمونه داخل پروژه
- **ساعات خروجی:** ویرایش ساعت‌های لوحه (روز عادی / پنجشنبه / جمعه) — در همین مرورگر ذخیره می‌شود
- **لیست پرسنل:** فایل LIST TABLE (یک‌بار؛ نمونه داخل پروژه بار می‌شود)
- **صبحکار / عصرکار:** از تقویم ابدی شیفت روی تاریخ فایل (قابل اصلاح دستی)
- **تقویم شیفت:** چرخهٔ ۶روزه از ۱۴۰۵/۰۷/۰۷ — روز ۱/۲، صبح، عصر، استراحت
- **کسری شیفت:** راهبران شیفت که در لوحه نیستند؛ اضافه‌کار در چاپ بولد و خاکستری
- **چاپ لوحه:** برگهٔ A4 شبیه فایل «لوحه اعزام» — تاریخ و ساعات همان روز

## تطبیق نام‌ها

جستجو فقط روی ساعت نیست. ستون‌ها از روی عنوان پیدا می‌شوند (جای ستون عوض شود هم کار می‌کند) و تطبیق با **مبدأ + ساعت + نقش** است.

## تکنولوژی

TypeScript، React، TanStack Start، SheetJS (`xlsx`). جزئیات در [TECHNICAL.md](TECHNICAL.md).

## نصب به‌صورت PWA (تقریباً آفلاین)

پیش‌نمایش داخل گراک داخل iframe است و مرورگر اجازهٔ نصب نمی‌دهد. از لینک GitHub Pages بالا در تب جدا استفاده کنید.

بعد از باز شدن آن آدرس:

- کروم: دکمه **نصب روی دستگاه** یا منوی ⋮ → Install app
- آیفون: Share → Add to Home Screen

بار اول باید آنلاین باشد. از آن به بعد:

- باز کردن اپ بدون اینترنت
- بارگذاری فایل `.xls` از خود دستگاه
- ویرایش ساعت‌ها (در همین مرورگر ذخیره می‌شود)
- ساخت خروجی اکسل

نمونه گزارش فقط اگر یک‌بار آنلاین گرفته شده باشد آفلاین کار می‌کند.
